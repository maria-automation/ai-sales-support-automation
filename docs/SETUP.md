# Setup

1. Import `workflows/online-school-ai-automation-sanitized.json` into your own n8n instance.
2. Create your own Telegram, OpenAI and Google credentials.
3. Replace `YOUR_SHEET_ID` with a test Google Sheet.
4. Replace `YOUR_MANAGER_CHAT_ID` with your own manager chat ID.
5. Replace `YOUR_BOT_NAME` with your bot name.
6. Assign your own n8n credentials to the corresponding nodes.
7. Test with demo data before connecting anything real.

The public export is a portfolio/demo artifact, not a one-click production deployment.
